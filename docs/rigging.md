# 자동 리깅 (2단계)

레이어가 나뉜 그림(PSD)을 넣으면 메시, 뼈, 가중치를 자동으로 만들어 `.l2d.json`으로
내보냅니다. 사람이나 Claude가 정하는 것은 **관절 위치**뿐이고, 나머지는 자동입니다.

```
PSD ──► inspect(격자 이미지) ──► rig.json 작성 ──► build ──► 구부림 테스트 ──► 애니메이션
          사람/Claude가 보고            관절 좌표만      메시·가중치 자동    자동 검사
```

예제: [`samples/kit`](../samples/kit) (여우 캐릭터. `source/kit.psd`, `rig.json`, `animations.ts`)

## 1. 그림 준비

- **레이어 하나 = 움직이는 부위 하나.** 팔, 다리, 꼬리처럼 휘는 부위는 통째로 한 레이어여도
  됩니다. 메시가 휘어지게 만듭니다.
- **가려진 부분도 그려 두세요.** 팔·다리 윗부분, 꼬리 뿌리처럼 몸통 아래로 들어가는 부분이
  있어야 움직일 때 빈 곳이 보이지 않습니다.
- **표정 등 교체용 그림은 숨긴 레이어로.** `eyes_closed`처럼 `기존레이어이름_접미사`로
  지으면 `eyes` 슬롯의 교체 그림으로 자동 등록됩니다.
- 레이어 마스크, 클리핑, 레이어 효과는 적용되지 않습니다. 내보내기 전에 래스터화하세요
  (적용되지 않으면 경고가 나옵니다).
- 고해상도(@2x)로 그리고 `rig.json`의 `scale`을 0.5로 두면, 게임 좌표는 절반 크기이면서
  선명한 그림을 씁니다.

## 2. 레이어 확인

```bash
pnpm rig inspect samples/kit/source/kit.psd
```

레이어 목록(이름, 위치, 크기, 숨김 여부)을 출력하고 `out/rig/kit-inspect.png`를 만듭니다.
합친 그림 위에 50픽셀 격자, 100픽셀마다 좌표, 레이어 상자가 그려져 있어서 관절 좌표를
그림에서 바로 읽을 수 있습니다. `--spec rig.json`을 붙이면 명세의 뼈도 겹쳐 그려서 위치를
확인할 수 있습니다.

## 3. 리그 명세 작성 (`rig.json`)

모든 좌표는 **PSD 픽셀 좌표**입니다.

```jsonc
{
  "name": "kit",
  "scale": 0.5,              // 스켈레톤 단위 / PSD 픽셀
  "origin": [600, 1544],     // 스켈레톤 원점이 될 픽셀 (캐릭터: 발 사이 바닥, 심볼: 중심)
  "bones": [
    // from = 관절(회전 중심), to = 뼈 끝(방향과 길이). parent 기본값은 "root"
    { "name": "hip", "from": [600, 1150], "to": [600, 1090] },
    { "name": "upper_arm_l", "parent": "torso", "from": [472, 784], "to": [428, 932] }
  ],
  "chains": [
    // 꼬리·머리카락·스카프처럼 긴 부위: 시작점만 주면 중심선을 따라 뼈를 자동 배치
    { "layer": "tail", "prefix": "tail", "count": 4, "parent": "hip", "start": [700, 1184] },
    { "layer": "scarf", "prefix": "scarf", "count": 2, "parent": "neck", "start": [672, 792], "end": [704, 930] }
  ],
  "parts": {
    "arm_l": { "bones": ["upper_arm_l", "forearm_l", "hand_l"] },  // 여러 뼈 → 휘는 메시
    "head": { "bone": "head" }                                     // 뼈 하나 → 사각형 그대로
  },
  "ik": [
    { "name": "leg_l", "bones": ["thigh_l", "shin_l"], "target": "foot_l_ik", "bendPositive": false }
  ]
}
```

### parts 옵션

| 필드 | 설명 |
|---|---|
| `bone` | 뼈 하나를 그대로 따라감(사각형) |
| `bones` | 여러 뼈로 휘는 메시. 가중치 자동 계산 |
| `slot` | 다른 레이어의 슬롯에 교체 그림으로 넣기 |
| `mesh` | `true`면 뼈가 하나여도 메시, `false`면 뼈가 여러 개여도 사각형 |
| `spacing` | 정점 간격(PSD 픽셀). 기본은 부위 두께의 1/3 (16~64) |
| `softness` | 관절이 섞이는 거리(PSD 픽셀). 작을수록 관절이 또렷함. 기본 정점 간격의 0.75배 |
| `smooth` | 가중치 다듬기 횟수. 기본 2 |
| `blend` | `normal`, `add`, `multiply`, `screen` |
| `skip` | 이 레이어 제외 |

`parts`에 없는 레이어는 자동으로 정합니다. 뼈가 레이어 그림을 지나가면 그 뼈들로 메시를
만들고, 지나가는 뼈가 없으면 가장 가까운 뼈 하나를 따라가게 합니다(보고서에 `(auto)` 표시).

### 발과 IK

다리를 IK로 움직이면서 발이 바닥에 붙어 있게 하려면:

1. 루트 밑에 IK 타깃 뼈(`foot_l_ik`)를 발목 위치에 둡니다.
2. 신발 쪽을 맡는 `foot_l` 뼈를 타깃 뼈의 자식으로 둡니다.
3. 다리 레이어를 `["thigh_l", "shin_l", "foot_l"]`로 묶습니다.

## 4. 빌드

```bash
pnpm rig build samples/kit/source/kit.psd --spec samples/kit/rig.json --animations samples/kit/animations.ts --out samples/kit
```

`samples/kit/kit.l2d.json`과 `samples/kit/images/`를 쓰고, 레이어마다 결과(사각형/메시,
정점·삼각형 수, 사용한 뼈)와 체인 관절 좌표를 출력한 뒤 구부림 테스트를 실행합니다.
테스트에서 오류가 나면 종료 코드 1로 끝납니다(`--allow-errors`로 무시 가능).
`--animations`에는 `{ 이름: 애니메이션 }` JSON 파일이나 `animations`를 내보내는 `.ts` 파일을 줍니다.

## 5. 구부림 테스트

애니메이션 전에 리그를 자동으로 검사합니다(`bendTest` in `@llm2d/core`).

- **관절 회전:** 메시를 휘게 하는 뼈를 ±45°(필수), ±90°(경고만) 돌려 봅니다.
- **IK 다리/팔:** 타깃을 뿌리 쪽으로 20% 당기고(웅크리기), 뿌리 기준으로 ±20° 돌립니다
  (각각 40%, ±40°는 경고만).
- **검사 항목:** 삼각형 뒤집힘(그림이 접힘 → 오류), 20% 미만으로 줄어듦, 4배 이상 늘어남
  (경고), IK 타깃이 셋업 포즈에서 닿지 않음(경고).

눈으로 확인하려면 자세별 이미지를 렌더합니다. 뼈마다 한 줄이고, 휘는 부위를 확대해 보여
주며, 접힌 칸은 빨간 글씨로 표시합니다.

```bash
pnpm render --file kit/kit.l2d.json --bend            # out/renders/kit-bend.png
pnpm render --file kit/kit.l2d.json --bend --stress   # 극단 자세까지
```

### 문제가 나오면

| 증상 | 해결 |
|---|---|
| 관절에서 접힘 | 관절 근처에 정점 추가(`spacing`을 줄임), `softness`를 키움, `smooth` 증가 |
| 멀리 있는 부분이 같이 끌려감 | `softness`를 줄임, 체인 `start` 위치 조정 |
| 다리가 발에서 떨어짐 | 애니메이션에서 엉덩이를 올릴 때 IK 타깃도 같은 타이밍으로 올리기 |

## 동작 원리

1. **윤곽 추출:** 알파 마스크를 3픽셀 넓혀(경계의 반투명 픽셀 보호) 가장 큰 덩어리의
   외곽선을 따고(Moore 추적), 더글러스-포커로 단순화한 뒤 긴 변을 잘게 나눕니다.
2. **메시:** 외곽선 + 뼈를 따라 놓은 점 + 엇갈린 격자의 내부 점으로 들로네 삼각분할을 하고,
   외곽선을 강제 변으로 고정(constrained Delaunay)한 뒤 바깥 삼각형을 버립니다.
3. **체인:** 레이어 모양을 세선화(Zhang-Suen)해 중심선을 얻고, 시작점에서 가장 먼 끝까지의
   경로를 같은 길이로 나눠 관절을 둡니다.
4. **가중치:** 각 뼈까지의 거리를 메시를 따라(측지 거리) 재고, "가장 가까운 뼈보다 얼마나 더
   먼가"로 가중치를 정합니다(`exp(-(d - d최소) / softness)`). 그래서 관절 근처에서만 부드럽게
   섞이고, 나머지는 가장 가까운 뼈만 따라갑니다. 마지막으로 메시 위에서 평균을 내 다듬고,
   정점당 뼈 4개까지로 줄입니다.
